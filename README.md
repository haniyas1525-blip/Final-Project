# E-Commerce Sales Analysis Dashboard

## 📊 Project Overview

This project analyzes an **e-commerce sales dataset containing 34,500 orders** to identify important business trends and patterns.

The analysis focuses on:

* Revenue performance
* Profitability
* Customer activity
* Product categories
* Regional sales
* Discounts
* Returns
* Payment methods
* Delivery performance

The project uses **Tableau Public** to create an interactive dashboard that makes the business insights easy to understand.

---

## 📁 Dataset

**Dataset Name:** `ecommerce_sales_34500.csv`

The dataset contains e-commerce transaction information such as:

| Column               | Description                    |
| -------------------- | ------------------------------ |
| `order_id`           | Unique order identifier        |
| `customer_id`        | Unique customer identifier     |
| `product_id`         | Product identifier             |
| `category`           | Product category               |
| `price`              | Product price                  |
| `discount`           | Discount applied to the order  |
| `quantity`           | Number of products purchased   |
| `payment_method`     | Payment method used            |
| `order_date`         | Date of the order              |
| `delivery_time_days` | Delivery time in days          |
| `region`             | Customer/order region          |
| `returned`           | Whether the order was returned |
| `total_amount`       | Total order amount             |
| `shipping_cost`      | Shipping cost                  |
| `profit_margin`      | Profit margin percentage       |
| `customer_age`       | Customer age                   |
| `customer_gender`    | Customer gender                |

## 📈 Key KPIs

The dashboard focuses on the following important metrics:

* **Total Revenue**
* **Estimated Profit**
* **Total Orders**
* **Unique Customers**
* **Average Order Value**
* **Return Rate**
* **Average Delivery Time**
* **Average Discount**

### Profit Calculation

Since the dataset contains `total_amount` and `profit_margin`, estimated profit can be calculated as:

```text
Estimated Profit = Total Amount × Profit Margin / 100
```

The Tableau Public dashboard contains multiple visualizations to provide a complete overview of the e-commerce business.

Displays the major business KPIs:

Shows estimated profit performance month by month.

#### 4. Customer / Order Growth

Shows changes in customer or order activity over time.

#### 5. Category Revenue Analysis

Compares revenue generated by different product categories.

#### 6. Regional Performance

#### 7. Returns Analysis
